ATLAS Offline software
========================

Welcome to [ATLAS](https://atlas.ch) Athena software! 

Please visit the [public documentation](https://atlas-software.docs.cern.ch/) for this project. 
To contribute or to read about our development workflow, follow the [developers' instructions](https://atlas-software.docs.cern.ch/athena/developers/). 

For ATLAS members, please see the [Atlas Computing Twiki](https://twiki.cern.ch/twiki/bin/view/AtlasComputing/AtlasComputing) for even more information.
