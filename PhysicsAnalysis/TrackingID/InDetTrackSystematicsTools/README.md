Track Systematics Tools
=======================

This package hosts a number of tools and algorithms to apply
systematic variations to tracks. The algorithms in this package are
designed to be configured in a Gaudi-based environment via
ComponentAccumulator.

Users interested in applying track systematics within the AMG Physics Analysis
Algorithms framework should consider the algorithms defined in

```
PhysicsAnalysis/Algorithms/TrackingAnalysisAlgorithms
```

A number of these tools are wrapped by algorithms there as well.

Note that the Gaudi-based and Analysis Algorithms are designed to fit
within different frameworks. Mixing and matching the algorithms may be
difficult. The underlying tools are identical.
