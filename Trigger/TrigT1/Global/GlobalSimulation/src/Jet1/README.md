JET1 algorithms for GlobalSimulation
===

This holds the source code for simulation of the JET1 algorithms for the GlobalSimulation

Global Jet AlgTools
---
This AlgTool produces a collection of Winner Takes All Cone jets (WTACone). It takes in CellTowers produced by the GlobalCellTowerAlgTool, and runs the implementation of the WTACone jets from TrigGepPerf.
